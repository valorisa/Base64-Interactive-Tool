## [2.0.0] - 2026-08-01

### Added

- Modular package architecture.
- Modern command-line interface based on `argparse`.
- Interactive mode separated from business logic.
- Pure Base64 codec module.
- Validation module with dedicated helper functions.
- Project-specific exception hierarchy.
- Comprehensive unit test suite.
- Modern Python packaging with `pyproject.toml`.
- English and French documentation.
- Project governance documents.
- GitHub-ready repository structure.

### Changed

- Complete refactoring of the original implementation.
- Clear separation of responsibilities across modules.
- Improved readability and maintainability.
- Simplified public API.
- Consistent documentation throughout the project.

### Removed

- Legacy monolithic implementation.
- Obsolete test suite from the original version.
