# Code of Conduct

## Our Commitment

We are committed to providing a welcoming, respectful and inclusive
environment for everyone, regardless of experience level, background or
identity.

The goal of this project is to encourage constructive collaboration and
knowledge sharing.

## Expected Behavior

Participants are encouraged to:

- be respectful and courteous;
- provide constructive feedback;
- welcome different viewpoints;
- accept feedback gracefully;
- focus discussions on improving the project;
- help create a positive environment.

## Unacceptable Behavior

The following behaviors are not acceptable:

- harassment or discrimination;
- personal attacks or insults;
- abusive or offensive language;
- deliberate intimidation;
- trolling or disruptive behavior;
- publishing private information without permission;
- any conduct that is inappropriate in a professional environment.

## Scope

This Code of Conduct applies to all project spaces, including:

- GitHub Issues;
- Pull Requests;
- Discussions;
- code reviews;
- any other official communication channel related to this project.

## Enforcement

Project maintainers are responsible for interpreting and enforcing this
Code of Conduct.

They may edit, remove or reject contributions that violate these rules.

Repeated or serious violations may result in temporary or permanent
restrictions from participating in the project.

## Reporting

If you experience or witness unacceptable behavior, please open a private
discussion with the project maintainers.

Reports will be reviewed fairly and handled with discretion whenever
possible.
